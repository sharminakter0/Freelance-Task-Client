# Freelance Task Marketplace

A dynamic platform where individuals can post small freelance tasks and freelancers can browse and bid on them based on skills, budget, and deadlines.

---

##  Live Website

 [Visit Live Site](https://ass10-freelance-task.web.app)

---

##  Key Features

 **Secure Authentication** using Firebase (Email/Password and Google login)
 **Post and Manage Tasks** with full CRUD operations (Add, Update, Delete)
 **Browse and Bid on Tasks** with detailed view and bid tracking
 **Responsive and Unique UI** inspired by modern freelance platforms
 **Dark/Light Theme Toggle** with smooth transitions
 **Protected Routes** with persistent login even after page reload
 **MongoDB Atlas + Express API** for fast and secure backend operations
 **Dynamic Task Filtering** with most recent deadlines shown first
 **SweetAlert2 and Toasts** for interactive user feedback

---

##  Tech Stack

- React
- React Router
- Firebase Auth
- Express.js
- MongoDB Atlas
- Tailwind CSS
- SweetAlert2 / React Toastify
- Vercel (Server) & Netlify/Firebase (Client)
